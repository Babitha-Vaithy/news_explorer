# React + Vite

Project Name: News Explorer

Project Description: In this project, I have worked on Main page where the header, search bar, about , footer will be presented. The user can click the Sign Up button and fill the required information for registration then user can Sign In their respective profile based on their email and password. They cannot view any page before the registration.

Once the profile is opened, user can view saved articles page and their profile name in header. User can search any information by using the search bar and also they can save the article by clicking the save icon. I worked on preloader (i.e) the content is searched and while waiting they will view an animated work and also if there is no content they will get notification that there is no exact the information what they searched.

In saved article page, they can view all saved articles with the count and also they can delete the article.

And finally the user can Sign out their repective profile.

Techniques and Technologies: React, javascript, HTML, CSS
